Asisten e-Kinerja

Kebijakan Privasi

Berlaku mulai: 15 Oktober 2026 · Pengelola: Nurhadi — ASN Kota Depok

Asisten e-Kinerja adalah ekstensi Chrome Manifest V3 untuk membantu pengguna menyiapkan dan menginput kinerja harian pada https://kinerja.bkn.go.id/. Produk ini merupakan inisiatif independen dan tidak berafiliasi dengan atau disahkan oleh BKN maupun Pemerintah Kota Depok.

Data yang diproses

DataTujuan dan lokasi
Baris kegiatan A:HValidasi, pencocokan, dan pengisian. Dibaca dalam memori; isian dikirim ke BKN ketika pengguna menjalankan Simpan.
URL spreadsheet dan nama tabMengingat sumber terakhir. Disimpan lokal melalui chrome.storage.local.
Nama akun yang terlihat, SKP, dan periodeMembentuk konteks target dan pemisahan catatan; diproses lokal.
Catatan progresDisimpan lokal untuk mencegah pengiriman ulang dan mencatat status, baris sumber, waktu, signature/hash, serta catatan keputusan.
Kalibrasi kolomSelector formulir disimpan sebagai pengaturan lokal.
Token OAuth GoogleDikelola Chrome Identity untuk permintaan Google. Token tidak ditulis ke log aplikasi.
Laporan statusDiekspor ke CSV atau dikirim ke Google Sheets sebagai tab baru setelah tindakan pengguna.

Cara data diperoleh

File dipilih pengguna. Spreadsheet dibaca setelah pengguna menghubungkan Google dan menekan Ambil/Perbarui data. Formulir dan kartu dibaca pada halaman BKN setelah ekstensi dijalankan. Ekstensi tidak meminta password BKN atau Google.

Akses dan transmisi

Data dikirim ke BKN saat pengguna menyimpan kegiatan. Google Sheets diakses sesuai izin Google yang diberikan pengguna. Kode acuan tidak mengirim isi kegiatan atau token ke server pengembang dan tidak memakai analitik pengembang. Fitur Google berkomunikasi dengan Google; pengisian berkomunikasi dengan BKN.

Scope acuan: https://www.googleapis.com/auth/spreadsheets.readonly untuk membaca spreadsheet yang dapat diakses akun, dan https://www.googleapis.com/auth/spreadsheets secara opsional untuk membuat tab laporan. Scope kedua memberi cakupan baca/tulis spreadsheet yang dapat diakses akun; alat menggunakannya pada sumber yang dipilih.

Penggunaan data Google

Informasi dari Google API dipakai hanya untuk menyediakan fungsi Asisten e-Kinerja yang dijelaskan kepada pengguna. Penggunaan mengikuti Google API Services User Data Policy, termasuk persyaratan Limited Use, serta Chrome Web Store Limited Use. Data tidak dijual, dipakai untuk iklan, penilaian kredit, atau pelatihan model AI.

Penyimpanan dan retensi

Pengaturan dan jurnal berada di profil browser selama masih disimpan oleh ekstensi atau pengguna. Tidak ada batas retensi tetap yang dijanjikan. Data yang dikirim ke BKN dan tab laporan Google mengikuti layanan terkait. Catatan lokal dapat berisi tanggal dan nama kegiatan; hash bukan jaminan anonimitas total.

Kontrol dan penghapusan

  • Ganti sumber atau lepas sesi Google melalui Pengaturan koneksi.
  • Cabut izin aplikasi melalui pengaturan koneksi pihak ketiga pada Akun Google.
  • Hapus data lokal melalui pengelolaan browser atau penghapusan ekstensi.
  • Penghapusan ekstensi tidak menghapus kegiatan BKN, spreadsheet, file bukti, atau tab laporan. Hapus melalui layanan terkait sesuai kewenangan.

Keamanan dan tanggung jawab pengguna

Koneksi Google API memakai HTTPS dan token dikelola Chrome Identity. Pengguna bertanggung jawab menjaga profil browser, akun, perangkat, serta akses file bukti. Jangan memasukkan data yang tidak diperlukan, termasuk password, token, API key, credential, atau data pribadi pihak lain.

Dukungan dan perubahan

Hubungi hadi4us@gmail.com. Kirim versi ekstensi dan pesan error yang sudah disamarkan; jangan kirim password, token, seluruh spreadsheet pribadi, atau data pasien. Perubahan material atas pemrosesan data akan dicantumkan pada halaman ini dengan tanggal pembaruan.
